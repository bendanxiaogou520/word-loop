## 中文

### 这是什么

一个纯本地的背单词 App，专攻四六级：**3920 个词**，每个词都带词根拆解、词源、例句和词频。

不要账号、不推送、不上传任何数据 —— 学习记录只存在你的手机里。

### 它比别人多做了什么

| 数据 | 覆盖率 |
| --- | --- |
| 词根词缀拆解 | 3542 / 3920（**90%**） |
| 词源（这个词怎么来的） | 3616 / 3920（**92%**） |
| 例句 | 3886 / 3920（**99%**） |
| 词频标签 | 3867 / 3920（**98.7%**，高频 446 / 常用 1334） |

背单词最难的不是记不住，是**不知道为什么是这个意思**。把词根和词源摊开，很多词一下就有逻辑了。

### 七个模式

| 模式 | 怎么玩 |
| --- | --- |
| 听音选义 | 听发音，4 个释义里选一个；答错立刻展开词根 + 例句 |
| 听音写词 | 听发音拼写，卡住可以要首字母 + 字母数提示 |
| 翻卡过词 | 正面单词音标，翻面看释义、词根、例句、词源 |
| 错词本 | 答错的、熟练度低的词自动进来，可一键专练 |
| 词根词缀 | 词根 174 / 前缀 50 / 后缀 94，可搜可专练 |
| 听整句 | 神经语音读一整句，句子里目标词挖空，4 选 1 填 |
| 词库浏览 | 五种筛选 + 搜索，点进去看单词详情页 |

### 其他

- **考试倒计时**：填考试日期，首页算「距今 N 天 / 还剩 R 词 / 每天得学 P 词才赶得上」
- **主题与配色**：4 档主题 × 6 套配色
- **数据**：发音与例句语音缓存、一键清空学习记录

## English

### What it is

A local-only vocabulary app for Chinese college English tests (CET-4/6): **3,920 words**, each with morpheme breakdown, etymology, example sentences and a frequency tag.

No account, no push, no uploads — progress stays on your phone.

### Data coverage

| Field | Coverage |
| --- | --- |
| Morpheme breakdown | 3,542 / 3,920 (90%) |
| Etymology | 3,616 / 3,920 (92%) |
| Example sentences | 3,886 / 3,920 (99%) |
| Frequency tag | 3,867 / 3,920 (98.7%) |

The hard part of vocabulary isn't memorising — it's not knowing *why* a word means what it means. With roots and etymology laid out, a lot of words click.

### Seven modes

Listen-and-choose · Listen-and-spell · Flip cards · Mistake list · Roots & affixes · Whole-sentence listening · Word browser.

### Install

Download the APK above (~1.1 MB), allow unknown apps once. Android 8.0+. Fully offline.
